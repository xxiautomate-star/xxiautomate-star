## ⚡ Acuvo — a creative AI platform

**A builder, a terminal agent, and a studio in one workspace.** Describe what you
want; watch it get built.

```bash
npm i -g acuvo-code && acuvo --login
acuvo "the invoice test is failing — work out why and fix it"
```
